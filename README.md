**Solmara Nights** — an original open-world crime game for the browser, set in the invented sunset coastal city of Solmara. On foot and behind the wheel: steal cars, run a three-mission story chain for the fixer Marina (First Wheels → Hot Cargo → The Pier Job), outrun a 0–5 star wanted system with police interceptors, fight the pier crew, grab cash pickups, then keep earning with endless errands. Lane-following traffic AI, wandering pedestrians, a live minimap, HUD with wanted stars and objectives, localStorage saves, and fully synthesized WebAudio (engine, sirens, shots) — all in plain static files under `game/`, no libraries, no network, split into single-job modules in `game/src/`.

## Run it

```sh
node serve.ts   # then open http://localhost:8080 — or hand it in with: MAKEFUN_OUTPUT_DIR=out node main.ts
```
